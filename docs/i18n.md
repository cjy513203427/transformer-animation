# 界面语言（中文 / English / Deutsch）

## 地址

| 语言 | 地址                 | `<html lang>` |
| ---- | -------------------- | ------------- |
| 中文 | `/attention`（原样） | `zh-CN`       |
| 英文 | `/en/attention`      | `en`          |
| 德文 | `/de/attention`      | `de`          |

根路径 `/`、`/en/`、`/de/` 是导读页，在第一个实验之前。所有实验路径相同，只多一个语言前缀；已有中文链接不变。页头右侧的语言切换保留当前实验和 URL hash（实验参数），所以分享的状态可以换语言打开。站内链接、分享链接和“上一实验 / 下一实验”都按当前语言生成（`localePath`）。Workers 的 SPA 回退与 Vite dev / preview 都会把 `/en/…`、`/de/…` 交给同一个 `index.html`。

## 机制

- 中文是源语言，原文留在代码里：普通字符串写 `T('中文')`，带变量写 `T('第 {#0} 步', n)`；JSX 里夹着公式或强调的整句写 `Tx('先看 {#0} 的形状', <Tex tex="Q" />)`。占位符用 `{#i}`，不用 `{0}`，避免和 TeX 的花括号冲突。译文可以调整占位符顺序。
- 译文在 `src/i18n/catalog/en.json`、`de.json`，键就是中文原文，按源码顺序排列，便于对照审阅。
- `src/main.tsx` 先按 URL 确定语言、加载对应目录（中文页面不加载），再导入应用。语言在整个页面生命周期内固定，所以模块可以在导入时就调用 `T()`。
- 计算层（`src/math/p1/*`）生成的张量名、指标名也用 `T()`。讲解代码按名字查数值（`c.metric(T('概率和'))`），两边是同一个中文键，换语言后自动对得上；`src/content/locales.test.ts` 会在英文、德文下把每个主题、每个预设、每一步都实际算一遍来核对。
- 内部错误信息（`throw new Error(…)`）不翻译，它们不显示给用户。
- 例外：位置编码实验的玩具词“我 / 爱 / 你”在 `PositionWidgets.tsx` 里用按语言写死的显示表（英文 man / bites / dog，德文 Mann / beißt / Hund），因为“我”在 Attention 示例里译作 “I / Ich”，同一个中文键不能有两种译法。

## 新增或修改中文文本

1. 照常写中文，但包在 `T(…)` 或 `Tx(…)` 里（第一个参数必须是字符串字面量）。
2. `node scripts/i18n.mjs todo [路径片段]` 列出未翻译的条目：hash、位置、占位符对应的代码、中文原文。
3. 把译文写进一个 TSV 文件，每行 `hash:中文开头几个字<TAB>英文<TAB>德文`。`:中文开头` 可选，用来防止抄错 hash；德文以空格结尾时在行末加 `<TAB>|`，避免编辑器删掉行尾空格。
4. `node scripts/i18n.mjs merge 文件.tsv` 合并；`node scripts/i18n.mjs check` 检查。
5. `npm test` 会再检查一遍：漏译、多余条目、占位符、`$` 数量、首尾空格、译文里残留中文、英德首尾空格是否一致。

修改中文原文后，旧译文会变成“多余条目”，新原文会变成“漏译”，测试会同时报出两者。

## 图里的文字

英文、德文通常比中文长，固定大小的方框和 SVG 画布最容易溢出：

- SVG 里放在方框内或靠近画布边缘的文字用 `components/FitText.tsx`（传入可用宽度 `width`）。放得下时与普通 `<text>` 完全相同；放不下时先在空格、连字符、“·” 处折行（`maxLines`，默认 2），再按需缩小字号（不低于 0.72）。方框高度只够一行时传 `maxLines={1}`。
- 很长的图注不要放在 SVG 里，放在图下方的 HTML 段落中，让它自然换行（例如 P1 机制图的 `.p1-svg-note`）。
- 缩到最小仍放不下的，改用更短的译法（例如 KV 立方体的 “2 KV”、架构图的 “× N”）。
- 一行里并排的图例或标签不要写死 x 坐标：按文字宽度依次排开，放不下就换到下一行（例如 `features/p1/Charts.tsx` 的 `legendLayout`，中文仍落在原坐标上）。标签旁边有参考线时，宁可换到点的另一侧，也不要压线。
- 页面标题区的按钮与眉题共用一行时，用网格让眉题占据按钮剩下的宽度，不要按中文按钮宽度预留固定空白。
- `tests/i18n.spec.ts` 会在桌面与手机尺寸、英文与德文下逐步检查：SVG 文字是否超出所在方框或画布，HTML 文字是否超出不可滚动的容器，以及文字是否互相重叠（SVG 标签之间、标签压到小图例色块或标记、HTML 文字行之间）。重叠检查不覆盖“文字压到大方框或连线”，这类问题仍需对照中文截图人工看。

## 翻译约定

- 英文译文参照原书英文版（<https://waylandz.com/llm-transformer-book-en/>）的术语、小节标题和类比。英文版是改写版：章与中文版一一对应，但第 21–24 章等小节结构不同，部分类比也换了（例如第 23 章的“luthiers / pattern books”、第 13 章的 bypass lane 与合奏排练、第 30 章的 PR 审阅分配）。
- 英文、德文页面的“原书”链接打开英文版对应章节（德文没有原书译本）；步骤标签写英文版真实存在的小节号与标题，如 “§10.3 Generating Q, K, and V”。
- 只出现在中文版里的例子或错误，说明里写明 “Chinese original” / „chinesisches Original“；英文版已修正的，顺带注明。
- 德文用 du；保留业界通用的英文术语（Attention、Query/Key/Value、Softmax、Token、Head、Cache、Prefill/Decode、Logit、Advantage）。
- 数字统一用小数点（不用德文小数逗号），避免和向量 `[1, 2]` 的分隔逗号混淆。
